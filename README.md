# Exploratory Data Analysis – Amazon Dataset

## Objective
To explore the cleaned Amazon product dataset using Excel and identify
important statistics, trends, patterns and anomalies.

## Tool Used
Microsoft Excel

## Analysis Performed
- Descriptive statistics
- Category analysis
- Rating analysis
- Discount analysis
- Price analysis
- Product engagement analysis
- Anomaly identification

## Visualizations
- Products by category
- Rating distribution
- Average price by category
- Price vs rating
- Top 10 products by rating count

## Key Insights
1. Electronics has the largest number of product records.
2. The average product rating is approximately 4.10.
3. The average discount is approximately 47.69%.
4. Average discounted price is lower than average actual price.
5. Some products have more than 90,000 ratings.
